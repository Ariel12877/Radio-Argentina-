# Iconos de Radio Argentina — Ariel / 1977

Incluye el emblema elegido (la A plateada/dorada y el año 1977 en dorado) exportado en tamaños habituales.

## Integración
1. Copiar la carpeta `icons/` al repositorio (renombrar esta carpeta de salida como `icons`).
2. Copiar `manifest.webmanifest` a la raíz del repositorio.
3. Insertar el contenido de `index-head-snippet.html` dentro del `<head>` de `index.html`.
4. Verificar que las rutas relativas comiencen en `./` para que funcionen en GitHub Pages bajo `/Radio-Argentina-/`.

## Archivos
- `icon-512.png`: Android / PWA.
- `icon-192.png`: Android / PWA.
- `icon-180.png`: Apple touch icon.
- `favicon.ico`: pestañas y accesos directos de escritorio.
- PNG adicionales: 1024, 384, 256, 152, 144, 128, 96, 72, 64, 48, 32 y 16 px.
- `icon-512.webp`: versión liviana para uso dentro de la interfaz.
